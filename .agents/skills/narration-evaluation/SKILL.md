# 合成ナレーション生成・試聴評価手順（narration-evaluation）

正本は `AGENTS.md`、`docs/REFERENCE-STYLE-POLICY.md`、`docs/AUTONOMOUS-DOCUMENTARY-PIPELINE.md`、`tickets/T125.md`。
このSkillは、知的好奇心探究型ドキュメンタリーにおいて、世界観に適合した高品質な日本語ナレーションを生成し、客観的な基準で人の比較試聴・評価を支援する手順を定義する。

> [!IMPORTANT]
> このSkillは音声生成と試聴評価の記録を支援するものであり、エージェントが人の試聴を代行して独断で品質合格と判定することはできません。採用の最終決定は必ず本人が行います。

---

## 1. ドキュメンタリー向け音響・声質要件

参考チャンネル（「考えすぎる葦」等）の音響分析により抽出された、視聴維持と知的納得感を生む4大音響基準:

### 1.1 声質・トーン（Voice Quality）
- **ピッチ（音高）**: 低音〜中低音域（F0中央値: 100〜140Hz相当の落ち着いた男性声、または落ち着いた低めの女性声）。
- **演出方針**: 過度な抑揚やハイテンション、アニメ調の誇張表現を排除し、淡々と事実・論理を語る知的なドキュメンタリー語り口を追求する。

### 1.2 話速（Speed Control）
- **標準速度**: **約5.2〜5.8文字/秒**（1秒あたり5〜6モーラ）。
- **緩急の原則**:
  - 一般的な解説YouTube（6.5〜7.5文字/秒）よりも意図的に遅めに設定。
  - 数値や重要概念の提示部分ではさらに減速（4.5〜5.0文字/秒）し、視聴者の理解を深める。

### 1.3 ポーズ制御・思考の間（Pause Control）
- **読点（、）**: 約0.3秒の微ポーズ。
- **句点（。）**: 約0.5〜0.6秒の明確な文末ポーズ。
- **段落・場面切り替え**: **1.0〜1.2秒の「思考の間」** を確保（ナレーションが途切れ、視覚図解やスポットライトの移動に意識を向けさせる）。

## 2. 音声品質チェックリスト

試聴時に確認すべき具体的な検査項目:

| カテゴリ | 検査項目 | 不良例と対策 |
|---|---|---|
| **アクセント・発音** | 専門用語・学術用語の平板化・誤読 | 「スーパースター」「スケーラビリティ」「二項対立」の頭高・平板の違和感をチェック。 |
| **数値・単位** | 数字や記号の正確な読み上げ | 「0.005秒」（れいてんれいれいごびょう）、「数百倍」（すうひゃくばい）等の脱落や不自然なイントネーション。 |
| **文末イントネーション** | 疑問文や反語のトーン | 問いの場面（「なぜ2位ではダメなのか？」）で過度に語尾が跳ね上がらないか。 |
| **音響ノイズ** | クリッピング・ブレス・ロボット感 | 生成境界でのポップノイズ、高音域の金属的歪み、不自然な無音ブツ切りがないか。 |

---

## 3. 比較試聴評価表（Audio Evaluation Matrix）

複数の音声候補（声色A、声色Bなど）を同一台本・同一区間で比較する際は、以下の5段階評価を用いる:

- **自然さ（naturalness / 1〜5）**: 音素の滑らかさ、人間らしさ。
- **発音・アクセント（pronunciation / 1〜5）**: 日本語アクセント、専門用語の正確さ。
- **ドキュメンタリー適性（documentaryFit / 1〜5）**: 低音・落ち着き・思考の間の演出適合度。
- **聞き取りやすさ（clarity / 1〜5）**: 暗黒背景・視覚情報と重なった際の明瞭さ。
