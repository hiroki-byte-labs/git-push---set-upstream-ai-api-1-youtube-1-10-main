# 仕様 v0.1
日本語の初学者向けに、日常に結び付く少し難しい概念や知識を説明し、生活への活かし方まで扱う（T070、2026-10-10のテーマ変更）。投資と心理は扱える題材の一部とする。10〜20分の長尺をYouTubeの1チャンネルへ制作・投稿する構想。本人による題材選定・考察執筆・台本承認・完成動画承認を当面必須とする。図解・字幕・ナレーション中心とし生成映像は必要箇所だけ。収益化は事業目標であり開発の完了条件・収益保証ではない。詳細はdocs/CHANNEL-POLICY.md。従来の例外通知だけの運用へ移行する場合は、この人の関与の方針を別途見直す。

計画予算は月2〜3万円、3か月8〜10万円。今回の課金承認ではない。

## M0/M1の境界
以下は既存の投資テーマ試作の実装範囲。新テーマの生成経路（テーマ別免責・導入文・出典の概要欄出力・一般テーマのfixture）はT103で実装済み（下記「テーマ別の台本」）。人の必須工程の強制はT104で行う。
M0は仕様・チケット管理・開発手順。M1は36秒・1280×720・24fpsのローカル試作。オリジナルの架空の場面から、字幕・3段階の図解・自作確認音を含むMP4を生成する。自然なナレーション、生成AI、実相場・投資リターンの数値、外部API、公開は含まない。確認音は音声トラック経路の模擬実装であり読み上げではない。長尺制作・自然な日本語音声の品質はM2/M4で検証する。

## データと構成
TypeScript CLI → ScriptProvider → AudioProvider → VisualProvider → MP4と検証情報。Publisherは明示的に無効化。既定native経路はNode 24以上とmacOSのSwift/AppKit、およびFFmpegが必要で、実行時npm依存なし。任意のRemotion経路はmotion-lab側のRemotion/React等とChromeを使用する。開発時にTypeScriptとNode型定義を固定導入。制作の既定経路ではn8n/Make、クラウド、常駐ワーカーは使わない（エージェント計測には別途SQLiteを使用）。台本下書きはエージェントの作業、承認済みPlanからの描画はCLIの処理と区別する。

企画は fixtures/sample.json、台本の条件は prompts/script.md、ジョブはGit対象外のoutputs。各ジョブは一意のID、版、入力ハッシュ、接続種別、進捗、費用0円、完成ファイルのハッシュを持つ。エラー時はfailed。M1では再実行は新ジョブで、途中再開・自動再試行はしない。

## 後続で必須の制御
承認は完成物の版/ハッシュに結び付け、変更時に失効。公開制限・審査を先行調査。費用は確定額に実行中見込額を加える。投稿成功後の応答喪失は照合してから処置する。公開APIの再試行で重複投稿させない。無人運用前には異常注入と非公開連続運転を行う。

チケット担当はhuman/agentへ移行。任意のエージェント名・モデル名を同じ作業ログschemaで記録する。旧codex担当はagentへ変更し、過去ログの実施者記録は保存。開始/終了/検査CLIとGit pre-commitで未記録・記録後変更を検知。Nodeの選択はPATHまたはNODE_BINで、特定AI付属の実行環境への自動依存なし。詳細と強制できる範囲はdocs/AGENT-WORKFLOW.md。

## 台本形式v2と制作の検査（2026-10-08、T041〜T044、T024、T033）
- 台本はschema 2（src/plan.ts）。ナレーション、字幕cue、図解4種（flow、compare、number、branch）、出典（https・確認日）を持つ。総尺は25分まで。v1は読み込み時に変換する。
- 制作前に安全検査（src/lint.ts）を行う。対象は禁止表現、出典のない数値、最終場面の免責。errorがあれば制作しない。
- 描画は文字を計測して縮小し、収まらなければ失敗する。図解は段階表示する。字幕は焼き込み（T106から既定）、ソフト、両方から選ぶ。
- native経路の完成動画検査: フレーム数の一致、ソフト字幕、確認音、描画画像とのPSNR、LUFSの記録。Remotion経路はT156で全映像/音声デコード、実フレーム数、映像/音声/コンテナ尺（許容差0.1秒）、必要stream、解像度/fpsとPCM統計を検査する。期待frame数は厳密一致とし、失敗/未実施はvideo-checkedに進めない。PSNRはnative固有のまま、RemotionのLUFS/true peak・字幕内容/時刻・場面ごとの確認音は未測定と明記する。実Remotionでの媒体検査の経路統合はT156の30秒実出力で確認済み。長尺/実ナレーションの品質受入れとは区別する。レイアウト等の固定レポート値も実文字計測の合格と同一視しない（src/remotion-visual.ts）。
- 台本・音声・描画は接続抽象と予算上限（既定0 USD）を通す。job.jsonはmock/local/realを区別して記録する。
- 承認は確認対象一式（動画、採用タイトル・概要欄・タグ・チャプター、字幕、サムネイル全案）の版に結び付き、変更で失効する（T095、src/review.ts、serve）。投稿は引き続き無効。
- 詳細と不変条件はdocs/HANDOFF.md。

## テーマ別の台本（2026-10-10、T103）
- 台本v2に任意欄`theme`（general/investment）と`intro`（導入文・出典id・fictional）を追加。schemaは2のまま。未知のthemeは拒否する。
- theme未指定は旧形式（投資と心理の試作）として投資テーマ扱い。既存の投資fixtureを一般テーマへ読み替えて検査を緩めない。
- 免責: investmentは最終場面で推奨・保証の否定、generalは結果を保証しない旨の否定。generalでも投資の語（銘柄・株価・NISA等）があれば投資の免責が必要。禁止表現・出典のない数値・具体例の架空/実例の区別・サムネイル文言の検査はテーマによらず適用する。
- 概要欄: 先頭に導入文。出典は文献名・URL・確認日を一覧にし、metadata.jsonの`sources`に場面番号と導入文での使用を保存する。URLの記録は主張の検証済みを意味しない。
- 導入文の欠落は本番尺（3分以上）でerror、試作はwarning。導入文は出典か架空の明示が必要（error）。
- 新テーマの無料サンプルは`fixtures/sample-general.json`（開発用の架空例。総務省統計局の公式ページを出典とする）。詳細はADR-017。

## 本人が担う工程（2026-10-10、T104）
- 制作案件（outputs/production-xxxxxxxx、kind=production-project）に、題材候補・本人の選択・本人の考察（版つき、本人執筆/整形版の区別）・台本の版・台本の承認/差戻し・制作した動画を追記で記録する。開発チケットとは別。
- 台本はrole: reflectionの場面を1つ持つ下書きに本人の考察を差し込んで作る。下書きのまま（未入力の目印）はlintのerror。台本の版は候補の内容・考察の版とハッシュ・台本ファイルのハッシュから作り、変更で台本承認が失効する。
- 制作（produce render）は未選択・考察未入力・台本未作成/古い・台本未承認なら拒否し不足を表示する。強制オプションなし。
- 完成動画の承認は確認対象一式に台本の版を加えて結び付け、現在の承認済み台本と一致しない動画は失効・承認不可。sampleは常にデモ、modeのない既存ジョブはデモ扱い。公開前の判定（publishReadiness）は本番の案件・本番の動画・現在の承認済み台本・動画承認を要求する。本番の案件では本人の工程をエージェント名で記録できない。詳細はADR-018。

## 見せ方（2026-10-10、T106）
- 文字は入れ物の枠の中で上下中央（または上寄せ）に置き、画面の区画（見出し行・題名・強調・図解・字幕・フッター）を重ねない。文字配置の検査結果をjob.json.layoutに記録する。
- 図解に集計の図（meter）を追加。flowは任意でmotion: travel（矢印が伸びて次の段が出る）。段の表示時刻はdiagram.revealで説明に合わせられる。
- 字幕の既定は焼き込み。字幕は本人希望により背景枠なしの白文字と控えめな影で、下部の専用区画に表示する（T144）。サムネイルは問い型・図解型・対比型の3案（thumbnail.keyword/contrastは任意）。
- 構成案と参考動画の観察はdocs/T106-DESIGN.md。構成の合意とサムネイルの選択は本人の確認待ち。詳細はADR-019。

## 参考動画の動きの解析・再現の検証環境（2026-10-10、T110）
- motion-lab/ の参考動画解析・比較は独立した検証用途。参考動画（利用を許可された手元の素材だけ。取得機能なし）の動きをFFmpegで解析してJSON（motion-lab/analysis@1）に保存し、Remotionで自作の図形により再現・レンダリングし、フレーム比較（SSIM/PSNR・動きの差）で差異を直す。
- T126でPlanVideo描画とPlan変換を本体VisualProviderへ統合済み。sample/produce renderの--renderer remotionで選択し、job.json.versions.rendererKindにlocal.remotionを記録する。Remotion等の依存配置はmotion-lab側で、native経路と併存。参考動画解析結果の自動制作接続や投稿を意味しない。ADR-020の「本体と独立」はT110時点の判断で、現在の描画統合にはこの追記を適用する。
- 観測できない項目は確からしさ（upper_bound/unknown等）と理由を付けて記録し、断定しない。詳細はmotion-lab/README.md。
