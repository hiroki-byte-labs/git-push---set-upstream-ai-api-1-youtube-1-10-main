# T145 人型と動きの差戻し対応

本人の要望: 「もっと人の形もリアルなピクトグラム」「動きや登場をなめらかに」「入れている参考動画を参考に実装」。T145初回は承認されておらず、同チケットの受入不足として修正した。

## 参照した入力と観察

- `motion-lab/reference1.mp4` / `reference2.mp4`。T111にある利用者指定の解析根拠と冒頭0:00〜1:44の指定を確認。元動画の画素・音声・輪郭のトレースは生成素材へ転用しない。
- 参考1の78〜88秒を0.25秒間隔で復号し、88秒の人物を拡大確認。首、肩、腕、左右に分かれた脚が読み取れる人型。人物は同時に全部出ず、順に薄い状態から明瞭になる。後から人物が増えても既出人物は消えない。
- 参考2の36〜46秒を0.25秒間隔で復号。数字の位置変化に続き、人物の列が時間差で増える。抽象的な単語だけでなく、対象を表す絵で説明している。
- 入口を探す概要タイルも確認したが、粗い間隔であるため動きの判定には上記10秒区間を使用。曲線の正確な係数やナレーション同期は測定していない。
- 既存の `analysis/reference_analysis.json` には過去の動きの記述が推論として記録されている。今回の直接復号による観察と、以前の仮説を混同しない。

## 初回実装で不足していた点

1. 人物の胴体が単純で、首・腕・脚の構造が十分に伝わらなかった。
2. Remotionは場面開始から12フレームで進捗が1になり、2秒以降に出る人物や線が最初から完成状態だった。
3. nativeはillustrationを連続描画の対象にしておらず、静止した段階表示になっていた。初回の代表静止画・全編再生完了だけの検証では、この不具合を見逃した。

## 今回の実装判断

- 独自の人物輪郭を新しく作図。丸い頭だけの記号から、首・肩・腕・腰・左右の脚・足先が連続したシルエットへ変更。写実画像や特定人物の再現ではない。
- 人物は0.7秒のフェードと12論理pxの小さな浮き上がり。群衆は0.09秒、配信先は0.18秒ずつ登場をずらす。線は0.85秒、光は0.95秒で連続変化させる。これらは観察を踏まえた設計値で、参考動画の実測値ではない。
- 開始と停止で速度・加速度が0になる補間を用い、各要素の登場時刻を基準に計算する。常時の揺れや装飾運動は追加しない。
- 人物輪郭と状態計算を `src/illustration.ts` へ集約。nativeは変化するフレームを24fpsで描画し、同一の静止区間だけ画像を再利用する。Remotionも同じ状態計算を使う。
- 字幕・台本・章構成は今回の描画比較のため同じ内容を使用。確認音のみで自然なナレーションは未接続。
