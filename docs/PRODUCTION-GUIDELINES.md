# 演出の指針（T085）
映像・音の演出（BGM、効果音、装飾、素材映像、アニメーション）を追加・変更するときに守ること。
- 根拠はdocs/RESEARCH-GROWTH.md。
- 作成: 2026-10-08、Claude Code（claude-opus-5-5）。
- 演出を追加するチケットは、本書の「追加前のチェック」を作業ログに記録してから実装する。

## 1. 原則
1. **本筋に関係しない演出を入れない（誘惑的詳細の回避）。**
   - 面白いが本筋と無関係な情報や素材は、学習を下げる（E17: 58研究、g=−0.33）。
   - 動画は理解のためのもので、飾りのためではない。
2. **注意は「今説明している要素」に向ける。**
   - 強調・指示・段階表示などの信号化は理解を助ける（E13）。
   - 視聴のピークは画面の切り替えと同時に起きやすい（E2）。
   - 演出は「次に見る場所」を示す目的に限って使う（T079）。
3. **ナレーションと同じ文を画面に重ねない。**
   - 全文字幕の焼き込みより、キーワード表示の方が有利（E12）。
   - 字幕は切り替え式にする（T078）。
4. **台本ごとに意味のある違いを作る（量産判定の回避）。**
   - テンプレートの色や配置だけを変えても、独自性にはならない（G19）。
   - 演出の差ではなく、内容（独自の分析・事例）で差を作る（T070の方針に従う）。

## 2. 追加前のチェック（作業ログに記録する）
| # | 確認すること | 不可の例 |
|---|---|---|
| 1 | その演出は、どの説明・どの要素への注意を助けるか（1文で言えるか） | 「にぎやかにするため」のBGM、内容と無関係なストック映像 |
| 2 | ナレーションの聞き取りを妨げないか（音量・帯域・タイミング） | 話している最中の効果音、歌詞のある音楽 |
| 3 | 画面の文字・図解を隠したり、読み取りを遅らせたりしないか | 字幕の上を横切る装飾、点滅 |
| 4 | 素材の権利と出典をdocs/ASSETS.mdに記録したか | 出典不明の音源・画像 |
| 5 | 合成・改変コンテンツの開示（G20）が必要になるか | 実在人物の合成音声や映像 |
| 6 | 投資判断を煽る効果がないか（lintの禁止表現と同じ考え方） | 上昇を連想させる効果音、札束の映像 |

## 3. 音（BGM・効果音）
- **既定は「BGMなし」。** 入れる場合は、上の表の#1〜#3を満たす理由を書く。
- **音量差の検査（BGMを実装するときに作る）**
  - ナレーションとBGMを別々の音声トラックとしてFFmpegのebur128で測り、積分ラウドネスの差（LU）をmedia-check.jsonに記録する。
  - **暫定基準: BGMはナレーションより15 LU以上小さくする。**
    - この値に研究上の根拠はなく、聞き取りを優先した仮の値。人の試聴（T077）で見直す。
  - ナレーションのない区間（冒頭・章の切れ目）だけ、BGMを上げる「ダッキング」を検討する。
- **効果音**: 場面の切り替えや強調の合図に限って使う。ナレーションと重ねない。

## 4. 映像・装飾
- 動き（フェード・スライド）は、段階表示や場面転換の合図として短く使う（0.5秒以内を目安）。実装（T079）では、フェードは約0.17秒、出現した段の縁取り強調は1秒。常時動く背景や装飾は使わない。
- 色は配色トークン（render.swiftのaccent、muted、panel）の範囲で使う。新しい色を足すときは、文字とのコントラスト比を検査する（T091）。
- 素材映像（生成AI映像を含む）は「その映像でしか伝わらない」場面だけに使う。費用の承認（T060）と開示（G20）も確認する。

## 5. 素材の記録
- 外部の素材（音源・画像・フォント・映像）を入れるときは、docs/ASSETS.mdに次を記録する。
  - 名称、取得元のURL、ライセンス、確認日、利用範囲（収益化動画での利用可否）
- 生成AIの素材は、使ったサービス、モデル、生成日、利用規約上の権利（docs/RESEARCH-AI.md）を記録する。
