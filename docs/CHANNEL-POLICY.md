# チャンネル制作方針

2026-10-10、T070。利用者のdocs/HUMAN-TASKS.md 1-2〜1-5の回答をCodexが転記・整理。未回答の見た目や声の好みは含めない。

## 題材と独自の価値
- 投資と心理に限定せず、日常に結び付く少し難しい概念・知識、面白い雑学を扱い、「明日からどう活かせるか」まで説明する。
- 自分がなぜ気になったか、どこで理解に困ったかという視点を出す。
- 初歩からAIと調べて理解を深める過程を、初学者に伝わる形にする。
- 調べた知識を実生活に結び付け、活用の指針を示す。
- 発信者の個人情報・身分を公開しない。回答に含まれた個人属性を公開用の設定や台本へ転記しない。
- 顔出しもアバターも使用しない（T092）。本人写真を素材へ流用せず、agentが題材を説明する図解や素材の候補を用意する。素材購入・有料生成の承認は含まない。

## 各動画で人が担う部分
形式は当面長尺のみ（T089）。物語を順序立てて伝え、検索流入を目指す。試作3本後に制作負担を見て形式を見直す。ショート機能は現段階では追加しない。

1. エージェントが列挙した題材・具体例から本人が選ぶ。
2. 考察の場面を本人が書く。AIが本人の考察や実体験を創作して代用しない。
3. 本人が台本全体を読み、必要な修正をして承認する。
4. 本人が完成動画を確認し、承認・差戻しする。

当面はこの人の関与を必須とする。従来の「例外だけ人に通知する」構想は、これらの工程を勝手に省略する根拠にしない。自動化を広げる場合は改めて方針を決める。工程の強制・記録はT104で実装した（`produce`コマンドと確認画面の制作案件ページ。READMEの「本人の工程を通す制作」）。

## 導入・出典・立場
- 具体的なニュースや事象から導入し、そこから概念を深掘りする。実在の出来事には確認できる出典を付け、架空の例は区別する。
- 概要欄に動画の導入と、動画で使った研究・調査・論文へのリンクを掲載する。AIが出典やURLを捏造しない。
- 資格はない、特記する利害関係はないという本人申告を、公開用文言へ整えた。公開用の定型文はconfig/channel.json。
- 利害関係は今後の動画でも永続的に「なし」と保証するものではなく、変化があれば更新する。
