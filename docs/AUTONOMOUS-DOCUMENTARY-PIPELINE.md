## 1. 概要と目的

「考えすぎる葦」のような、**知的好奇心を刺激するダークテーマ・ミニマルモーショングラフィックス動画**（10〜20分尺）を、AIエージェントおよび自動化パイプラインによって**高再現性・完全自律的**に制作するための要件・技術基盤・準備項目を定義する。

素材の無断複製や表層的な模倣ではなく、同チャンネルの10本の動画から**本質的な情報設計・視覚構造・心理誘導の法則**を抽出し、プログラムで再現可能なアーキテクチャとして具体化する。

## 3. 自動制作パイプラインに必要な技術スタック

同要件の動画をエンドツーエンド（台本生成からMP4出力・検査まで）で自動生成するためのアーキテクチャ：

```
[企画・リサーチ] (LLM + 学術文献照合)
       ↓
[台本・構成生成] (構造化Plan JSON + タイムコード推定)
       ↓
[音声合成 (TTS)] (自然な低音ナレーション + 音素アライメント)
       ↓
[モーション生成] (Remotion / React コンポーネント合成)
       ↓
[レンダリング & 音響] (Chrome for Testing + ffmpegダッキング)
       ↓
[自動媒体・レイアウト検査] (PSNR, 文字衝突, LUFS音量, WCAG AAA)
       ↓
[成果物一式出力] (MP4, VTT字幕, サムネイルPNG, metadata.json)
```

---

### 3.1 レイヤー別必要技術

#### (1) 企画・台本生成レイヤー（Script Engine）
- **プロンプトエンジニアリング**:
  - **構造化プロンプト（Schema-Enforced Generation）**: 逆説、学術理論、比喩的章題、本人の考察を必須スロットとするJSON出力。
  - **メタファー辞書の定義**: ナレーションの各段落に対して、どの視覚メタファー（Spotlight, MetricBar, CausalFlow, SilhouetteGroup）を使うかをLLMに自動指定させる。
- **事実照合・出典チェック**:
  - 論文・公的統計のURL・文献名・発表年・主張内容を検証し、虚偽（ハルシネーション）のない出典ブロックを自動生成。

#### (2) 音声・音響エンジン（Audio Engine）
- **自然な低音ナレーション音声**:
  - 要件: 落ち着いた理性的な語り（スピード: 約5.2〜5.8文字/秒、ピッチやや低め、文末ポーズ 0.3〜0.5秒）。
  - 実装候補: ElevenLabs（Adam / George系クローン）、VOICEVOX、Google Cloud TTS Journey音声、Azure Neural TTS。
- **ミリ秒単位のアライメント抽出（Forced Alignment）**:
  - 音声波形から各文・各単語の正確な開始・終了ミリ秒（cue）を抽出し、Remotionのフレーム番号（30fps/60fps）に完全同期させる。
- **自動音響ミキシング（ffmpeg Audio Filter）**:
  - アンビエント・ドローン系の背景音楽（BGM）を、ナレーション発話区間中に自動で -18dB〜-20dB に減衰させる（Auto-Ducking）。

#### (3) モーション・グラフィックス描画エンジン（Motion Engine）
- **Remotion（React）フレームワークの完全活用**:
  - 宣言的コードによる1920x1080 30fps/60fpsのピクセル単位レンダリング（T114で検証済み）。
- **共通プリミティブ・コンポーネントライブラリ**:
  1. `<TheVoid />`: `#0a0a0c` の暗黒空間と微細な背景テクスチャ。
  2. `<Spotlight focalX focalY radius intensity />`: 動的スポットライトレイヤー。
  3. `<ProgressiveBar bars total easing />`: cubic-bezierで滑らかに伸びる比較・棒グラフ。
  4. `<SilhouetteActor type="winner|crowd" highlighted count />`: 人型シルエットの動的配置。
  5. `<CausalConnector from to progress style="arrow|line" />`: 概念をつなぐトラベルパス。
  6. `<BurnInSubtitle text active />`: 画面下中央、白文字、微細ドロップシャドウの焼き込み字幕。

#### (4) サムネイル自動生成エンジン（Thumbnail Engine）
- **極太見出し抽出**: 台本から最大6〜8文字の核心フレーズを抽出（例: 「2位の生存戦略」）。
- **対比レイアウト合成**:
  - 左右2分割または上下2分割で、2つの象徴的シンボル（金色の王冠 vs 暗い群衆、伸びる棒 vs 低い棒）を配置。
  - コントラスト比 10:1以上の白文字、ワンポイントのアクセントカラー（青 `#3b82f6` または黄 `#eab308`）。

#### (5) 媒体検査・安全検査（QA Engine）
- **文字・図形の衝突検査（Collision Detection）**:
  - 各レイヤーのBounding Boxをフレームごとに検査し、文字ずれや図形の重なりをゼロにする。
- **音量基準検査**: YouTube推奨の統合音量（-14 LUFS ±1.0 LUFS）への自動ノーマライズ。
- **フレーム完全性検査**: 予定フレーム数と実出力フレーム数の完全一致（ffprobe）。

## 5. 結論

「考えすぎる葦」スタイルの動画は、高度な3D CGや実写撮影を必要とせず、**「構造化された知見」「暗黒空間でのスポットライト」「意味を持ったベジェアニメーション」「洗練された極太対比サムネイル」**という、**コード（Remotion / TypeScript）による完全自動生成と最も親和性が高い表現形態**である。

上記の技術スタックおよびプリミティブコンポーネントを段階的にリポジトリへ統合していくことで、人手の編集作業を一切介さず、テーマを与えるだけで最高品質の解説動画を量産する体制を構築できる。
