## 1. 目的と背景

利用者の視聴所感（`docs/HUMAN-TASKS.md` T007回答）において以下の改善要望が提示された：
1. **文字ずれ**: 枠の外へのはみ出しや中央ずれの解消。
2. **演出・動き**: 「ただのパワポ」に見える静的な段階表示から、題材の意味や思考過程を表現するアニメーションへの進化。
3. **構成**: 「判断の前に確かめる3つの観点」のような箇条書きではなく、導入の出来事・本人の視点・生活への活かし方が流れるストーリー展開。
4. **字幕**: 画面下中央のクリアな焼き込み字幕。
5. **サムネイル**: 汎用テンプレートの文字替えではなく、核心的な問いと対比が一目で伝わるデザイン。

本方針書は、参考動画（`irBD6OF8d2Q`「なぜ2位ではダメなのか？【スーパースター経済学】」）および同チャンネルの複数動画を横断的に分析・抽象化し、素材や絵柄の無断複製（丸パクリ）を避けつつ、優れた情報設計・演出構造の原則を取り入れた当チャンネル独自の制作方針を策定するものである。

## 2. 参考チャンネルの横断的分析（観察事実と制作選択の分離）

### 2.1 分析対象動画群（直接観察サンプル）
- **動画A**: 『なぜ2位ではダメなのか？【スーパースター経済学】』（`irBD6OF8d2Q`）
  - 観察事実: 夜の都市背景に金貨の山と人物、二人の人型と青いスポットライト、暗闇空間の遠景に小さな人物群。白字幕は黒い帯状下地を伴う場面あり。
- **動画B**: 『なぜ「牛の解体ショー」は存在しないのか』（`2hPS0cpLunM`）
  - 観察事実: 魚の解体舞台、台上の大きな魚、作業者、客席の人物を描いたフラットなイラスト情景。左右で魚と牛を対比。白字幕＋黒い帯状下地。
- **動画C**: 『なぜ月は「スマホで撮る」と小さくなるのか？』（`yfmHbtoP0sw`）
  - 観察事実: 夜の街、巨大な月、スマホを構える人物を一つのイラスト場面に構成。肉眼とカメラの対比。白字幕。

### 2.2 観察事実と制作選択の区別
過去の方針書において、一部動画の局所的観察から「画面は常に純黒」「字幕座布団は廃止」といった過度な一般化が行われていた。T149・T150における監査に基づき、**直接観察された客観的事実**と、**当チャンネルの制作上の選択**を明確に分離する：

| 項目 | 観察された事実（参考動画群） | 当チャンネルの制作選択（Design Choice） |
|---|---|---|
| **タイトル** | 「なぜ〜なのか？【学術領域A×学術領域B】」の形式。身近な疑問＋権威ある学問分野。 | 採用。知的好奇心探究型ドキュメンタリーの統一フォーマットとして活用。 |
| **背景・色彩** | 暗黒・スポットライト（動画A）だけでなく、色面のあるイラスト情景や舞台セット（動画B・C）も実在。 | **暗黒空間（#0a0a0c）はスーパースター試作での選択肢の1つ**。題材に応じた情景表現や色面イラストも場面型（archetype）として許容する。 |
| **画面構成** | 単一の図解形式に固定せず、情景（月・舞台）、対比（魚vs牛、1位vs2位）、数量（金貨の山）、関係（光・矢印）を切り替える。 | **場面型（Scene Archetypes: 情景、対比、数量、因果、余韻）の導入**。台本内容に応じた動的選択を行う。 |
| **アニメーション** | 緩急のあるイージング（cubic-bezier）によるフェードイン、線の伸長、光の拡散。 | 採用。0.7秒のスムースイージング（OutQuart）による滑らかな連続動作を共通基盤とする。 |
| **サムネイル** | 見出し（6〜8文字）＋明確な対比（1人 vs 多数、◯ vs ◯）＋アクセント1色。人物写真・アバター不使用。 | 採用。高コントラスト・ミニマル対比サムネイル（a/b/c案）を維持。 |
| **字幕** | 画面下部中央、1〜2行。**少なくとも複数動画で黒い帯状下地（ボックス）が確認された**。 | **原則としてクリアな白文字焼き込み（ドロップシャドウ付き）を基本としつつ、背景イラストと干渉する場合は帯状下地も選択肢とする**（普遍的な「座布団禁止」とは断定しない）。 |

## 3. 抽象化された4大設計方針

### 3.1 構成案方針（Narrative Structure Policy）

プレゼン型の「項目列挙」から、**知的好奇心探究型のストーリー構成**へ移行する。

```
[序章: 命題提示] (〜1.5分)
  実在のニュース・発言・身近な違和感から素朴な問いを立てる（「二位じゃダメなんでしょうか？」）
       ↓
[第1章: 直感の解体] (3〜4分)
  常識的な理解と現実のデータのギャップを示す（例: わずか0.005秒差で賞金が何倍も開く）
       ↓
[第2章: 理論とメカニズム] (3〜4分)
  学術概念・メカニズムを図解と動きで解説（例: スーパースター経済学、スケーラビリティ）
       ↓
[第3章: 構造の一般化] (3〜4分)
  個別の例から身近な社会現象や日常の構造へ広げる
       ↓
[第4章: 本人の考察] (1〜3分) ★当チャンネルの独自価値
  発信者本人の視点（「どこで迷ったか」「なぜ気になったか」「調べた本音」）を提示
       ↓
[終章: 活かし方と結び] (〜1.5分)
  明日からの視点の変化、生活への活かし方、余韻を残す問いかけ
```

- **原則**:
  1. **序章で問いを立てる**: 実在の出来事（出典あり）または身近な場面から問いを提示する。
  2. **章ごとに1つのサブクエスチョン**: 比喩的で魅力ある章題（例: 「0.005秒の段差」「二番目に高い山の憂鬱」）を冠する。
  3. **本人の考察を核に据える**: AIの要約ではなく、人間（本人）の考察場面を独立して配置する。

---

### 3.2 動き・演出方針（Motion & Staging Policy）

「スライドの紙芝居」を脱却し、**概念の意味を動的に伝えるモーションデザイン**を定義する。

1. **ダークフォーカス & スポットライト演出**:
   - 暗黒空間（#0a0a0c）をベースとし、話題の中心となる要素だけに光（radial-gradient）またはアクセント色（#3b82f6）を当てる。
   - 複数の比較対象がある場合、比較される側をトーンダウン（不透明度0.3〜0.5）させ、主役を際立たせる。
2. **プログレッシブ・メトリクス（順次伸長グラフ）**:
   - グラフ（棒グラフ、メーター、ピクトグラムの列）は一度に表示せず、ナレーションの文脈に合わせて滑らかに伸長させる。
   - イージング曲線: `cubic-bezier(0.16, 1, 0.3, 1)`（急速に立ち上がり、最後になめらかに減速するOutQuart/OutExpo系）。
3. **因果を結ぶラインとトラベル（Travel & Flow）**:
   - 前の事象から次の事象へ移行する際、細いアクセントラインや矢印が伸び（travel）、接続した瞬間に次のノードがフェードインする。
4. **文字・図形の階層的出現（Staggered Entrance）**:
   - 見出し（先に出現）→ アクセントライン（左からスライド）→ 図解・ピクトグラム（中央フェードイン）→ 字幕（文末に合わせて切り替え）。
   - 各レイヤーの座標・余白を厳格に分離し、文字ずれ・重なりを原理的に排除する。

### 3.3 サムネイル方針（Thumbnail Policy）

クリックベイト（煽り・嘘）を排しつつ、知的好奇心を最大化する**高コントラスト・ミニマル対比サムネイル**を採用する。

```
+-----------------------------------------------------------+
|                                                           |
|    [ 核心フレーズ ]           [ 視覚的対比シンボル ]      |
|    (大見出し: 6〜8文字)                                   |
|                                ◯ vs ◯                     |
|    例: 「2位の生存戦略」       (1人の勝者 vs 群衆)        |
|        「似た地獄を選ぶ脳」    (アクセントカラー 1色)     |
|                                                           |
+-----------------------------------------------------------+
（背景: #0a0a0c 漆黒 / 文字: 白 #ffffff / 強調: 青 #3b82f6 または 黄 #eab308）
```

- **原則**:
  1. **文字数は最大6〜8文字**: スマホ一覧で一瞬で認識できる極太ゴシック。
  2. **明確な対比構図**: 左右または上下で「勝者 vs 敗者」「1人 vs 群衆」「常識 vs 逆説」を対比させる。
  3. **色数は最大3色**: 黒（背景）、白（文字）、アクセント1色（図形強調）。
  4. **人物写真・アバター不使用**: 抽象ピクトグラムまたは幾何学図形のみを使用。

---

### 3.4 字幕形式方針（Subtitle Policy）

視界を妨げず、ナレーションの理解を正確に補佐する**洗練された焼き込み字幕**とする。

- **配置**: 画面下部中央（Y = 940〜970px、1080p基準）。
- **文字仕様**:
  - フォント: 視認性の高い角ゴシック（Hiragino Sans / Noto Sans JP）。
  - カラー: 純白（#ffffff）。
  - サイズ: 32〜36pt相当（スマホ横画面およびPC/TVで読みやすい最適サイズ）。
  - 行数: 1〜2行（1行最大20〜24文字、句読点や意味のまとまりで改行）。
- **下地・ボックス**:
  - 暗黒背景ではクリアな白文字焼き込み＋微細ドロップシャドウ（blur: 4〜8px, opacity: 0.6）を標準とする。
  - イラストや明色背景などコントラストが低下する場面では、半透明の帯状下地（黒バー）を許容する（参考動画でも実用されている）。

### 3.5 場面型（Scene Archetypes）方針（T150）

ナレーションの説明内容や物語の流れ（Beat）に応じて、単一の図解に頼らず最適な場面型（Archetype）を選択する：

| 場面型 (Archetype) | 役割と視覚表現 | 動きの目的 (Motion Purpose) | 代表的モチーフ (Motif) |
|---|---|---|---|
| **情景描写 (`scenery`)** | 題材固有の環境・背景・登場人物を提示し、直感的な状況把握を促す。 | 登場人物や環境要素の段階的出現、視線誘導。 | `social-division`（共通基盤から二極化する集団）、夜街と月など |
| **対比 (`contrast`)** | 2つの要素・立場・数値の不均衡や対立を明瞭に対比する。 | 左右への分割展開、光と影のトーンダウン、ラインの急伸。 | `ranked-rewards`（1位と2位の格差）、`tolerance-boundary`（寛容と不寛容） |
| **数量/データ (`data-quantity`)** | 格差の拡大、分布、蓄積、世代交代に伴う確率的推移を図示する。 | 棒の順次伸長、分岐木の成長、消失する枝のフェード。 | `branching-tree`（名字の分枝過程と絶滅）、プログレッシブメーター |
| **関係/因果 (`causal-relation`)** | 主体間の情報の伝播、ネットワークの広がり、防衛境界を可視化する。 | 細い線のトラベル（Travel Line）、光の拡散、境界線の形成。 | `attention-concentration`（注目の収斂）、`digital-reach`（信号伝播） |
| **章の余韻 (`resonance`)** | 章のまとめや動画の結びにおいて、核心シンボルを静かに佇ませる。 | 微細な呼吸（ブリージング）、集約された単一シンボルの光背。 | `lineage-convergence`（極少数の名字への集約）、動的均衡の佇まい |

- **選択規則**:
  - `hook`（問い・導入）: `scenery` または `contrast` で素朴な疑問や常識との落差を提示。
  - `body` / `example`（理論・メカニズム・事例）: `causal-relation` または `data-quantity` で因果や数理を動的に解説。
  - `recap` / `reflection`（まとめ・本人の考察）: `resonance` で核心シンボルの余韻を残す。

## 5. まとめ

本方針は、参考チャンネル「考えすぎる葦」の優れた表現技法（ミニマリズム、暗黒空間でのスポットライト、概念を可視化する動的グラフ、高コントラスト対比サムネイル）を抽象的な設計原則として昇華したものである。
これにより、当チャンネル独自のテーマ（日常の疑問・知的好奇心・個人の思考実験）において、視聴維持率と信頼性を両立する高品質なモーショングラフィックス動画の自動制作が可能となる。
