# 台本の判断前チェックリスト（T084）

台本v2の各場面に任意の`practice`配列を付ける。各項目はその場面のナレーションの**一文そのまま**（句点や疑問符を含む）にする。生成器は意味を推測して助言を補わない。1項目80字、台本全体12項目まで。空配列、途中の語句だけの抜粋、制御文字、`< >`、未知の出典は拒否する。

```json
{
  "narration": "これは架空の練習です。比べる品をメモしましょう。",
  "practice": ["比べる品をメモしましょう。"],
  "fictional": true,
  "sources": []
}
```

実際には既存の必須欄（title、seconds、cues、diagram等）も必要。出典つきの実践にはその場面の`sources`を使う。出典がない場合は`fictional: true`で架空の練習だと明示する。これは根拠のある助言の代用品ではない。原文・場面と出典の対応を保存する機能であり、出典がその助言を裏付けるかの意味の照合は台本の審査で行う。本人の考察や承認の工程は従来どおり。

`sample`と`produce render`の各ジョブに次を出す。

- `checklist.json`: 原文、場面番号、架空の区別、出典id・番号・題名・URL・確認日、画像ページ仕様。
- `checklist.txt`: 項目・場面・出典番号と、参照した文献の一覧。
- `checklist-1.png`以降: 1280×720、3項目ごとにページ分割。出典番号は同梱テキスト・概要欄と対応する。
- `checklist-report.json`: AppKitで実計測した枠・描画位置・文字サイズ・コントラスト・収まり。

項目未指定の旧台本にも「実践項目の指定がありません」とテキスト・画像を出す。固定の一般助言を足すことはない。概要欄にはチェックリスト全文を含める。実践項目つきの概要欄が5000バイトを超えたらジョブはfailedとして停止し、項目を勝手に切り捨てない。画像が枠に収まらない場合も停止する。

画像には既存の`render.swift`（AppKit）の文字計測・縮小処理を使う。映像のnative/remotion選択と独立して同じ画像になる。画像生成は現時点ではmacOSが必要。確認画面にテキスト・JSONへのリンクと全ページの画像を出し、確認対象の版に含める。変更・追加・削除で既存承認は失効する。チェックリストを持たない既存ジョブの承認版は維持する。

動画末尾の呼びかけは`role: "action"`で明示する。最後または最後から2番目の1場面だけに置き、台本にpracticeがあり、ナレーションと字幕の両方に「チェックリスト」の案内が必要。既存のdiagramと字幕で呼びかけを描き、nativeでは場面の札も表示する。最後の場面の音声・字幕の免責検査は従来どおり必須。生成器が承認済み台本に場面を自動追加することはない。

開発例: `./scripts/run src/cli.ts sample --plan fixtures/checklist-demo.json`。本人の入力や承認を経ていない架空のデモで、自然音声ではなく自作確認音を使う。検証時はsample-render-verification Skillの隔離コピーで実行し、既存outputsを保持する。
