## 3. 差戻し・採用変更の手順
採用候補を変更する場合:
```bash
./scripts/run src/cli.ts revise <jobId> --field thumbnail --to thumbnail-b.png --reason "b案の方がスマホでの視認性と対比が明確" --by "本人の名前"
```
変更後、承認ハッシュが自動的に失効するため、確認画面または `cli.ts review <jobId> approve ...` で新版を承認します。
