# say音声の尺と安全停止（T170、2026-10-17）

`sample --audio say` / `produce render --audio say` はcueごとに実WAVのPCM長を測定し、字幕枠を超える場合は場面番号・cue番号・実発話秒数・割当て秒数を表示して停止する。発話を切り捨てたり、承認済みPlanの秒数を自動で変更したりしない。失敗した合成からaudio.wavを書き出さない。

超過時は原稿を短くするか、下書きのcue・場面の尺を広げる。本人の考察を含む本番案件では `produce script` で新版を作り、事実・権利確認と本人の再承認を行う。元の承認済みファイルを直接書き換えない。

枠内に収まる発話は全PCMサンプルをそのまま配置し、残りだけ無音で埋める。端数秒の境界は絶対時刻からサンプル位置を計算し、cueごとの丸め誤差で末尾が欠けるのを防ぐ。T170の改善は音声欠落と配置の検査であり、声色や発音の主観評価は別。
