チケットの「結果と検証証跡」を自分で書く場合は、作業ログの開始と終了が必要です（AGENTS.mdの規約）。
1. 開始する。

   ```bash
   ./scripts/run src/worklog-cli.ts start T070 --agent 'あなたの名前（人）' --model human --model-source unknown --request 'T070の方針決定を記録する'
   ```

2. 表示された`logs/…/WORKLOG.md`の全節と、tickets/T070.mdの「結果と検証証跡」を書き、statusをdoneにする。
3. docs/STATUS.mdに1行追記する。
4. 終了する（ディレクトリは手順1の表示に合わせる）。

   ```bash
   ./scripts/run src/worklog-cli.ts finish logs/日付/作業ID --status completed
   ```

5. 確認する。

   ```bash
   ./scripts/run src/cli.ts check
   ```
