## 目的
参考動画（利用を許可された素材だけ）の動きをFFmpegで解析してJSONに保存し、Remotion + React + TypeScriptで自作の図形により演出を再現・レンダリングし、参考動画とフレーム比較して差異を直す流れを、10秒程度の動画で検証できる最小環境を用意する。

## 実施範囲
- 本体（実行時npm依存なし）と分けたサブプロジェクト `motion-lab/`。Remotionはこの中だけに固定版で導入する。
- Remotion公式Agent Skills（remotion-dev/skills）を版を固定して `.agents/skills/` に導入し、プロジェクト作成・合成・レンダリングで参照する。
- 検証用の参考動画は、許可済みの外部素材がまだないため、本作業で数式から作る10秒の合成動画（自作素材、正解値つき）とする。解析は正解値を読まない。
- 解析: シーン切替の検出、動きのある区間の特定、区間の連続フレーム抽出、図形ごとの開始・終了時刻、位置・大きさ、種類、方向・速度、イージング、色・形・配置の推定。推定できない項目はunknownや下限として理由を残す。
- 再現: 解析JSONを入力とするRemotionの合成を作り、実際にレンダリングする。
- 比較: フレームごとのSSIM/PSNR、比較画像、生成動画を同じ解析器にかけた動きの比較。差異を直して再比較する。

## 対象外
- 第三者の動画の取得・解析（許可の確認は本人。T111）。
- 元動画の画素・音声・フォント・ロゴの流用。音声の解析と再現。
- 重なり・遮蔽・文字・写真・3D・粒子など複雑な素材の解析。本体の制作パイプライン（src/）への組込み。
- Remotionの商用ライセンス判断、有料API、デプロイ、push、投稿。

## 受け入れ条件
- `motion-lab/` の手順どおりに、参考動画の作成→解析→JSON保存→Remotionレンダリング→比較が実行できる。
- 解析JSONに、シーン、動きの区間、抽出フレームの場所、図形ごとの時刻・位置・大きさ・種類・方向・速度・イージング・色・形・配置と、各項目の確からしさ（測定/推定/不明）が入る。正解値との照合結果が残る。
- 推定できない項目（画面外の開始位置など）をunknownまたは下限として扱い、断定しない。
- Remotionで実際にレンダリングした動画と参考動画の比較結果（SSIM/PSNR、比較画像、動きの差）が残り、見つけた差異の修正前後が記録されている。
- 解析部の単体試験と型検査が成功する。本体のcheck・試験・型検査を壊さない。

## 検証方法
`motion-lab/` の一括実行で全工程を実行し、比較報告と正解照合を確認する。単体試験（node --test）とmotion-labの型検査、リポジトリの `./scripts/verify` を実行する。出力の数値は作業ログのevidenceに保存する（動画本体は保存しない）。

## 結果と検証証跡
2026-10-10 done（Claude Code / claude-opus-5-5、作業回 logs/2026-10-10/232110-T110-15494c02）。合成動画（自作素材）での最小検証環境の完成であり、実在の参考動画での検証はT111の後。
- 構成: `motion-lab/`（Remotion 4.0.534・React 19.2.3・TypeScript 5.9.3を固定、pnpm-lock.yaml）。本体の実行時npm依存なしの方針は変えない（ADR-020）。手順と限界は motion-lab/README.md。
- 公式Agent Skills: remotion-dev/skills の remotion-best-practices をコミット32b241b（version 4.0.534）で `.agents/skills/remotion-best-practices/` へ取り込み（`motion-lab/tools/fetch-remotion-skills.ts`、SHA-256を motion-lab/remotion-skills.lock.json で照合）。create-videoでの雛形作成、合成の登録・calculateMetadata・interpolate/Easing・premountFor、レンダリング、Studioでのプレビュー確認をSkillの手順で実施。
- 解析（tools/analyze.ts）: シーン切替（差分＋FFmpeg scdet）、動きの区間、区間の連続フレーム（PNGと番号つき一覧）、図形ごとの開始・終了（小数フレーム）、位置・大きさ・角度・不透明度、種類、方向・速度、イージング（14候補、雑音に対する有意差で estimated/ambiguous/unknown）、色・形（角丸半径を含む）・配置。確からしさを measured/estimated/ambiguous/upper_bound/lower_bound/unknown で付け、観測できない項目は unresolved に理由つきで列挙。動画の取得機能はなく、`--rights` での許可の根拠の記録が必須。
- 再現（src/Reproduction.tsx）: 解析JSONのチャンネルをinterpolate/Easingで評価し、SVGの自作図形で描く。元動画の画素・音声は不使用。解析した色・形（measured）と独自配色・角丸（house）の2種。
- 検証結果（out/final、合成動画10秒・1280x720・30fps・6図形・2シーン）: 正解照合67/67（開始が観測できない4件は upper_bound と開始値unknownで報告）。measuredの比較はSSIM平均0.99939・最小0.99889、PSNR平均48.41dB、動きの差は全図形で基準内（位置の最大誤差0.19px、イージング6/6一致）。houseは動きの判定に合格。
- 差異の修正（1回目の比較 evidence/iter1-compare-before-fix.md → 最終）: ①観測できない区間をモデルの外挿で描き、参考動画にない帯の小片が6フレーム早く出た → 観測されたフレームだけ描く。②生成動画の解析で大きさ変化（縦長→横長）を90度回転と誤認 → 主軸の長さが一定のときだけ回転。③不透明度9%の観測で縁が欠け高さを98pxと測った → 背景との差がしきい値の3倍未満の観測は幾何に使わない。④独自配色の角丸（半径18px）を矩形と判定 → 角の深さから角丸半径を推定。⑤観測できない開始のモデル時刻が実行ごとに±9.5フレームぶれた → 不確かさを付け、1フレームを超えるものは識別不能として判定にも使わない。修正前後の比較・照合は evidence/ に保存。
- 試験: motion-lab 12件成功（イージングのRemotion本体との一致、当てはめ、断定しない判定、画素計測）、型検査（src・tools/tests）成功、eslint（Remotion公式設定）0件。本体の試験191件・型検査も成功（変更なし）。
