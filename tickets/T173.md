## 目的
T165でサムネイルの原寸（1280x720）での寸法・破損・文字衝突・コントラスト検査が実装され、T167で縮小画像（320x180, 160x90）のプレビュー比較が整備されたが、縮小時の可読性判定は人の目視に依存している。YouTubeモバイルアプリ等の超縮小表示（160x90や120x68）において見出し文字が潰れて判読不能となる問題を自動検知する品質検査ゲートを拡充する。
## 実施範囲
`src/thumbnails.ts` に縮小画像の文字領域コントラスト維持率・エッジ検出による文字線判読性測定処理を追加する。見出しフォントが細すぎる、あるいは縮小時に背景に埋没してコントラスト比が3.0未満に低下する場合に警告または拒否（issues追加）を行う判定ロジックを実装する。単体テストを作成する。
## 対象外
人による主観的な美的評価の自動化、外部視線追跡API。
## 受け入れ条件
- 縮小画像（160x90等）に対して文字領域の視認性スコア（コントラスト・エッジ維持）が算出される。
- 潰れ・埋没が発生するサムネイルに対して `checkThumbnailQuality` が issues を検知して安全停止または警告を発する。
- 正常なサムネイルではパスし、実測レポート（`thumbnails-report.json`）に縮小視認性メトリクスが追記される。
- 単体テスト・型検査が合格する。
## 検証方法
合成縮小画像を用いた境界値・異常系の単体テストを作成し検証する。
## 結果と検証証跡
1. `src/thumbnails.ts` に純粋Node.jsでの軽量PNGデコーダー `decodePngRgba`、および超縮小表示（160x90等）における文字領域コントラスト・エッジ明瞭度測定処理 `measureScaledLegibility` を実装。
   - コントラスト比下限（`MIN_SCALED_CONTRAST = 3.0`）、エッジ強度下限（`MIN_SCALED_EDGE = 0.25`、Sobel勾配強度）、コントラスト維持率下限（`MIN_CONTRAST_RETENTION = 0.20`）の合否判定ロジックを導入。
   - `checkThumbnails` および `checkThumbnailQuality` において縮小画像（160x90優先、320x180）が存在する場合に自動的に測定を実行し、視認性不合格時に issues 追加と安全停止判定（`status = 'fail'`）を実施。
   - 検査実行時に `thumbnails-report.json` へ `scaledLegibility` メトリクスを自動追記・永続化する処理を統合。
2. 単体テスト `tests/thumbnails.test.ts` に正常系、低コントラスト埋没異常系、文字線消失ベタ塗り異常系、品質ゲート・レポート自動更新テストを追加（全11件合格）。
3. 全体テストスイート `npm test`（全394件合格）、TypeScript型検査 `npm run typecheck`（エラー0件）合格を確認。
