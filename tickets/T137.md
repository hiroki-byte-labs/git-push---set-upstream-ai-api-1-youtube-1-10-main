## 目的
カテゴリ動向と個別動画/チャンネルの成長状況を、調査・比較に使える形式で閲覧できるようにする。
## 実施範囲
CLIまたはローカル画面の構成を選び、期間・カテゴリ・動画/チャンネルで絞り込める表/時系列レポート、取得日時・データ鮮度・標本条件・指標定義・制約の表示、CSV等の安全なエクスポートを実装する。
## 対象外
公開Webサービス、YouTubeへの投稿、データ取得の自動スケジュール運転。
## 受け入れ条件
- カテゴリトレンドと動画/チャンネル個別推移を指定条件で表示・出力できる。
- 古い/不足データ、観測期間、出典、指標の意味と比較限界を画面/出力に明記する。
- 無データ・異常値でもクラッシュせず、合成データで再現可能。
## 検証方法
合成データでCLI/画面表示、フィルター、エクスポートを検証し、内容と指標を照合する。
## 結果と検証証跡
2026-10-13（Claude Code / claude-opus-5-5、logs/2026-10-13/153559-T137-4c49572b）:
- 構成はCLI（`./scripts/run src/trends-cli.ts`）。ローカル画面は作らず、表（text）・CSV・JSONを出す。src/trends-report.ts（レポート構築・整形）、src/trends-cli.ts（status / import / collect / report / policy / purge / delete / export）。
- 絞り込み: 期間（--as-of・--window・--stale-days）、出所、地域、カテゴリ、動画、チャンネル、件数。カテゴリ構成比、動画・チャンネルの伸び、取得値の推移（series）。
- 明記: 出典（合成/API）、地域、基準時刻・観測窓・収集期間、データの経過日数、取得時刻時点の値であること、派生値はYouTube提供値でないこと、構成比はチャート上位の内訳でありYouTube全体ではないこと、登録者数の切り捨て誤差、行ごとの注記と理由コードの説明。
- 安全なエクスポート: CSVの式注入対策（=,+,-,@,タブ,CRで始まる文字列に'）、注記は#行、--outは一時ファイルを使わず直接書く（履歴とは別）。
- 異常系: 無データ・不正な指定・壊れた取込ファイル・ロック残り・破損した履歴・ポリシー停止・キー未設定・模擬レスポンスなしでクラッシュせず、終了コードを分ける（docs/TRENDS-OPERATIONS.md）。
