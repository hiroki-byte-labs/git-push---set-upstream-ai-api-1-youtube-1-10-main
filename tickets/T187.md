## 目的
T174で実装した `optimizeSubtitleLines`（1行15〜22字を目安に文節・助詞境界で改行）は、2026-10-17のT120再監査で制作経路に未接続（`src/plan.ts` の再エクスポートと単体試験だけ）と分かった。現在の焼き込み字幕は、native（`scripts/render.swift` の `byWordWrapping`）とRemotion（`BurnInSubtitle.tsx` のブラウザー折り返し）がそれぞれ枠幅で折り返すため、語の途中や助詞の前で行が分かれうる。表示側の改行を文節境界にそろえる。
## 実施範囲
焼き込み字幕の描画直前に、cue本文へ文節境界の改行を入れる経路をnative/Remotionの両方へ接続する（台本・cue・VTTの本文は変えない。VTTには改行を入れるかを決めて記録）。2行に収まらない場合の扱い（縮小・cue分割・失敗）を既存の文字配置検査（T106/T155）と整合させる。
## 対象外
cue分割の規則変更（T174の範囲）、形態素解析エンジンの導入、字幕の見た目（書体・影）の変更。
## 受け入れ条件
- native/Remotionの焼き込み字幕で、`optimizeSubtitleLines` と同じ位置で改行される（両経路の行分割が一致）。
- 改行後も文字配置検査（はみ出し・区画の重なり）が合格し、収まらない場合は黙って切り捨てず検査で失敗する。
- 隔離コピーで短い実MP4を両rendererで生成し、代表フレームの目視と独立デコードで確認する。既存outputsを変更しない。
## 検証方法
単体試験（行分割の一致、2行超過の扱い）、`./scripts/verify`、`.agents/skills/sample-render-verification/SKILL.md` に従う隔離実生成と代表フレームの確認。
## 結果と検証証跡
2026-10-17 done（Claude Code / claude-opus-5-5 runtime、logs/2026-10-17/033708-T187-c685b693）。
- 接続: `src/subtitle-optimizer.ts` に `subtitleDisplayText` を追加（1行20字を優先し、2行に収まらないcueだけ36字まで1字ずつ広げる。36字はnative 30pt×36=1080pt<1140pt、Remotion 34px×1.04×36≈1273px<1536pxの1行容量）。native は `buildRenderSpec` が各フレームに `subtitle`（表示文字列）を入れ、`scripts/render.swift` はそれが無ければ停止する。Remotion は `toRemotionPlanProps` の各cueに `display` を持たせ、`BurnInSubtitle` は `whiteSpace: 'pre'`（ブラウザー折り返しなし、`overflowWrap: anywhere` 削除）。
- 行の選び方: `optimizeSubtitleLines` を貪欲詰めから「行数最小→境界の質（句読点後 < 次が漢字等 < 次がひらがな）→行長のそろい」のDPへ変更（貪欲版は fixtures で「ふり返りや／すく」「するも／のでは」と語中で切っていた）。cue分割が使う `tokenizeJapanesePhrases` は不変。
- 検査: native は NSLayoutManager で実際の行（矩形・文字）を `render-report.json` に記録。`src/layout.ts` は字幕の行数>2、行数の不一致、行の文字の不一致を不合格にする。Remotion は DOM Range の行矩形の行数を照合し、cue測定の照合も `display` に変更。
- VTT・台本・cue本文は改行を入れない（VTTはプレーヤーの折り返しに任せる。cueに元からある改行はVTTと同じ規則で残す）。
- 単体試験 `tests/subtitle-display.test.ts`（6件: 優先幅/拡張、2行不可の55字cueを切り捨てず3行で返す、native/Remotionの表示文字列一致、VTT・Plan不変、文字配置検査の合否、語中改行の回避）。全437試験・`tsc --noEmit` 成功（作業回open中は `verify` 先頭の check が止まるため個別実行、finish後に `./scripts/verify`）。motion-lab の `tsconfig.json` 型検査はHEADで失敗していた未使用変数4件を除去して成功（`tsconfig.tools.json` の既存22件は無関係で未対応）。
